# System-level boundary, with kernel and app pointer tracks

Status: accepted (2026-11-08)

The course teaches AOSP/AAOS system-level work only: build, boot, Binder/services, HAL/VHAL, CarService, SELinux, debugging, OTA, compliance. Kernel internals and app development are real OEM needs, but each is a course of its own; including them would halve the depth of the core. Instead, every lecture ends with curated pointers, and two standalone pages (Kernel path, App path) order those subjects as a system engineer meets them. This keeps the course's promise narrow enough to keep, without stranding learners at the boundary.
